# Content Agent Dashboard — Project Memory

This file is context for Claude Code. Read it at the start of every session.

## What this project is

An AI Content Agent Dashboard built in three phases:

1. **Content Intelligence Agent** — collects Instagram + competitor data via Apify.
2. **Dashboard** — five AI agents operating on that real data.
3. **Telegram bot** — receives reports generated by the agents.

## The five agents

1. **Ideator** — content ideas from trends, competitor performance, historical data.
2. **Hook & Script Writer** — hooks, scripts, captions, CTAs, SEO hashtags.
3. **Content Planner** — posting calendar + optimal schedule.
4. **Performance Analyst** — engagement tracking, top content, patterns, recommendations.
5. **DM Manager** — DM summaries, categorization, suggested replies, collab spotting.

## Working rules (do not violate)

- Build one verified step at a time. Never generate the whole project at once.
- Never skip verification. Ask "Did this work correctly?" after every step.
- Secrets live in `.env` only. Never hardcode secrets. Never commit `.env`.
- Prefer modular files over large ones. Separate UI / logic / services / utils.
- TypeScript everywhere. Zod for validation. Explain why each new file exists.
- Update existing files instead of replacing them when possible.

## Tech stack

Node.js (LTS), TypeScript, Vite, React, Tailwind CSS, shadcn/ui, Recharts,
