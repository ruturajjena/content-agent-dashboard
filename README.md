# Content Agent Dashboard

**Live dashboard:** https://ruturajjena.github.io/content-agent-dashboard/

An AI-powered content operations center for Instagram, built in three phases:

1. **Content Intelligence Agent** — pulls my Instagram + competitor data (Apify).
2. **Dashboard** — five AI agents operating on real data.
3. **Telegram bot** — delivers reports generated by the agents.

## The five agents

| Agent | Job |
|---|---|
| **Ideator** | Content ideas from trends, competitors, and my history |
| **Hook & Script Writer** | Hooks, scripts, captions, CTAs, SEO hashtags |
| **Content Planner** | Posting calendar + optimal schedule |
| **Performance Analyst** | Engagement tracking, top content, patterns, recommendations |
| **DM Manager** | DM summaries, categorization, suggested replies, collab spotting |

## Commands

| Command | What it does |
|---|---|
| `npm run scrape` | Fresh Apify scrape → `dashboard/data.json` (~$0.49) |
| `npm run fetch -- <datasetId>` | Rebuild data from an existing Apify dataset ($0) |
| `npm run dashboard` | Start the dashboard dev server (http://localhost:5173) |
| `npm run telegram:chatid` | Auto-detect your Telegram chat id |
| `npm run report` | Send the daily digest to Telegram (`--dry` prints, `--test` pings) |
| `npm run automate` | Full pipeline: scrape → data.json → Telegram (`--skip-scrape` = $0) |
| `npm run schedule` | Run the pipeline daily on a cron (`--now` runs once) |

## Automation & scheduling

Schedule runs **twice a week (Mon & Thu, 09:00)** to conserve Apify credit
(~$0.49/scrape ≈ $4/mo). Adjust via `REPORT_CRON` in `.env`.

**Local (laptop):** run the built-in scheduler and leave it open:

```bash
npm run schedule            # fires at REPORT_CRON (Mon & Thu 09:00 local)
```

**Local (always-on Mac), system cron** — survives closed terminals:

```bash
# crontab -e  → add (runs Mon & Thu 09:00):
0 9 * * 1,4 cd ~/Content-Manager && /usr/local/bin/npm run automate >> ~/content-agent.log 2>&1
```

**Deployment (recommended): GitHub Actions.** The workflow in
`.github/workflows/daily-report.yml` runs the pipeline in the cloud on a
schedule — no server, runs even when your laptop is off. Add these repo
secrets: `APIFY_TOKEN`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`.

## Public dashboard (GitHub Pages)

The dashboard is published at
**https://ruturajjena.github.io/content-agent-dashboard/** via
`.github/workflows/deploy-pages.yml` (rebuilds on any push under `dashboard/`).

The published site reflects the committed `dashboard/data.json`. To refresh the
public view with new data:

```bash
npm run scrape                     # fresh data (~$0.49)
git commit -am "Refresh data" && git push   # triggers a Pages rebuild
```

> Note: the twice-weekly Telegram job does **not** update the public dashboard
> (it doesn't commit data back). Push a new `data.json` to refresh Pages.
